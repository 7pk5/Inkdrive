# Inkdrive tour video: shot list (about 1 minute)

Use the DEMO setup so none of your own data shows: fake account maya@example.com with sample drawings, folders and tags.

## Set up
1. The demo server must be running (a Terminal tab opened by Claude; its data lives only in memory, so if it stopped, ask Claude to start and re-seed it).
2. chrome://extensions: only the demo build (folder `demo-build`) turned on, your normal Inkdrive off.
3. Chrome window about 1440x900, bookmarks bar hidden (Shift+Cmd+B), no other tabs. excalidraw.com open on a blank canvas.
4. Open the Inkdrive side panel. If already signed in, sign out from the avatar menu so sign-in can be shown.

## Record
Press Shift+Cmd+5, choose "Record Selected Portion", drag over the Chrome window, then Record. Stop from the menu bar.

## Shots
1. 0:00 Blank excalidraw.com. Point at the Inkdrive button beside the library. Say: "Excalidraw saves only in this browser. Inkdrive saves to your own private cloud."
2. 0:08 Click the Inkdrive button. The side panel opens on the sign-in screen. Pause 2 s.
3. 0:14 Click Dev sign-in, type maya@example.com, sign in. Say: "You sign in with Google." (The store build shows the Google button.)
4. 0:22 The welcome screen shows New drawing, Upload, New folder. Close it.
5. 0:28 The file list: move over the drawings, folders and tag chips.
6. 0:34 Click "Product launch plan". It opens on the canvas with no page reload. Pause 2 s.
7. 0:42 Draw a small shape. Point at the saved status in the panel. Say: "Autosave keeps it up to date."
8. 0:50 Type "wing" in Search, then clear it. Click a tag to filter.
9. 0:56 "..." menu of "Weekly notes", Version history. Show the revisions, close.
10. 1:02 Open the avatar menu: Autosave, theme, Privacy. End on the Inkdrive button.

## After
- Trim in QuickTime (Edit, Trim). Upload to YouTube (Unlisted is fine) and paste the link in the store listing's promo video field.
- Switch back: remove the demo build from chrome://extensions and turn your normal Inkdrive back on.
